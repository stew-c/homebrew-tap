# Stewartcoombs Tap

## How do I install these formulae?

`brew install stewartcoombs/tap/<formula>`

Or `brew tap stewartcoombs/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "stewartcoombs/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
